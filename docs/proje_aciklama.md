# Proje Açıklaması

Bu proje, Pardus kullanıcılarına sistem durumu hakkında sade ve anlaşılır bilgilendirme sunabilen bir yardımcı araç geliştirmek amacıyla hazırlanmıştır.

Teknik sistem verileri çoğu kullanıcı için karmaşık olabilmektedir. CPU kullanımı, RAM doluluğu ve disk kapasitesi gibi veriler uzman kullanıcılar için anlamlı olsa da yeni kullanıcılar için yorumlanması zor olabilir.

Bu proje, bu teknik verileri sadeleştirerek kullanıcıya anlaşılır durum mesajları sunmayı hedeflemektedir.

## Amaç

- Teknik sistem verilerini sadeleştirmek
- Kullanıcı dostu bilgilendirme sunmak
- Sistem durumunu hızlı analiz etmek
- Eğitim ortamlarında yardımcı araç geliştirmek

## İlk Sürüm Özellikleri

- Disk doluluk analizi
- RAM durumu bilgilendirmesi
- CPU durumu bilgilendirmesi
- Durum sınıflandırması (İyi / Dikkat / Kritik)

## Gelecek Geliştirmeler

- Gerçek RAM ölçümü
- Gerçek CPU ölçümü
- GUI arayüz
- Canlı izleme paneli
- Bildirim sistemi
