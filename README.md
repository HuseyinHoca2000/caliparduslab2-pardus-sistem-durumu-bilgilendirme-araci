# ÇalıPardusLab2 Pardus Sistem Durumu Bilgilendirme Aracı

Bu proje, Pardus işletim sistemi üzerinde çalışan cihazların temel sistem durumunu kullanıcı dostu bir şekilde analiz edip bilgilendirme sunan yardımcı bir araç geliştirmeyi amaçlamaktadır.

## Proje Amacı

Birçok kullanıcı CPU, RAM, disk ve sistem yükü gibi teknik kavramları anlamakta zorlanabilmektedir. Bu proje ile teknik verileri sadeleştirerek kullanıcıya anlaşılır sistem durumu bilgileri sunan bir araç geliştirilmesi hedeflenmektedir.

## Hedefler

- Sistem durumunu analiz etmek
- Teknik verileri sadeleştirmek
- Kullanıcı dostu bilgilendirme sunmak
- Eğitim kurumları için yardımcı araç geliştirmek

## Temel Özellikler

- CPU durumu analizi
- RAM kullanımı analizi
- Disk doluluk kontrolü
- Kullanıcı dostu durum mesajları
- Offline çalışma

## Hedef Kullanıcılar

- Öğrenciler
- Öğretmenler
- Pardus kullanıcıları
- Eğitim kurumları

## Kullanılan Teknolojiler

- Python 3

## Çalıştırma

```bash
python3 src/pardus_sistem_durumu.py
